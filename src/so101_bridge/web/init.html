Calibration: motors vs file

What the calibration file is

lerobot turns raw motor steps into degrees with this file: 0° of each joint is the middle of its min…max range. Every taught pose (rest, chess board, painting, waypoints) is stored in those degrees.

The motors keep their own copy of homing offset, min and max. If the file is lost (a cleared ~/.cache), rebuild it from the motors: this writes the file only, never the motors or the torque. Each save also keeps a copy in config/calibration/.

Joints marked ext have widened limits in limits.json. After a normal run, while the arm stays powered, their min/max registers can hold the widened values (RAM only). A mismatch there is expected, and the rebuild uses the range logged in var/bridge.log for them.

Guided recalibration

Only for a rebuilt arm, a replaced motor or a calibration that cannot be recovered. It moves 0° of every joint, so the rest pose, chess board, painting setup and waypoints must all be taught again. Try rebuild calibration file from motors first.

lerobot's own steps (SerialMotorsBus.record_calibration, what lerobot-calibrate runs), one button each. Every button that changes torque or motor registers asks for confirmation.

Homing pose (from lerobot)


    
Every joint in the middle of its travel: upper arm vertical, forearm horizontal pointing forward, wrist in line with the forearm, roll centred, gripper half open. It does not have to be exact; the sweep measures the real ends.
